# 🧠 知识地下城 · 答题闯关

一个把「答题」和「爬塔」结合的 AI 知识闯关小游戏：**答对才能挥刀，答错就挨打**，越往深处题越难。

**▶ 立即游玩**：<https://slatinwine.github.io/knowledge-dungeon/>（自动进入全区共享版）

## 玩法

- 每道题限时 15 秒，答对攻击敌人，答错/超时被反击
- 剩余时间 ≥60% 时伤害 ×1.5；连对 3 题触发心流追加伤害
- 通关后三选一奖励卡：逻辑强化、智慧回甘、反思之刺、从容不迫……
- 每 10 层一个 Boss（西瓜暴君 / 黑暗瓜神 / 万年瓜祖），血厚攻高，通关奖励 ×3
- 全局排行榜自动记录最高分的 3 位玩家（名字 · 层数 · 答对数 · 正确率）

## 题库 · 342 题 · 四级难度

| 难度 | 内容 | 出现层数 |
|---|---|---|
| ★ 基础 | AI 概念、厂牌产品、日常生活化题 | 1 层起 |
| ★★ 进阶 | Transformer、RLHF、MoE、训练推理基础 | 5 层起 |
| ★★★ 高阶 | Mamba、YaRN、SWE-bench、评测与安全 | 10 层起 |
| ★★★★ 面试档 | DeepSeek（MLA/GRPO/MTP/DualPipe）、OpenAI、Anthropic、Google、Meta、国内厂牌等 157 道面试真题风格 | 20 层起 |

选项顺序每局随机，同一难度抽空才会重洗——打到 40 层以上基本就是在模拟大厂二面。

## 技术实现

- 纯单文件 HTML，无构建、无外部依赖，克隆即玩
- 云端排行榜基于 WorkBuddy Cloud（云数据库 + RLS：所有人可读、可提交、不可删别人成绩）
- 音效由 WebAudio 实时合成，无音频文件
